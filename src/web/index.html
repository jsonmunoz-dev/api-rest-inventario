Inventario de una tienda

Esta página usa una API REST real conectada a una base de datos PostgreSQL. Prueba vender o reponer productos: el stock se actualiza en la base de datos y la API impide vender más unidades de las que hay.

¿Qué está pasando por detrás?
  • La tabla se carga con GET /api/v1/products.
  • “Vender 1” llama a POST /api/v1/products/:id/movements con {"type": "out", "quantity": 1}.
  • La salida se registra en una transacción con SELECT … FOR UPDATE; si no hay stock suficiente, la API responde 409 y no cambia nada.
